- 도구: Codex 이미지 생성(`codex exec`, codex-cli 0.169.0). 참고 그림 세 장을 `-i` 로 붙였습니다.
- 호출: `codex exec --cd <작업 폴더> --sandbox workspace-write "<프롬프트>" -i <화담> -i <협재> -i <북한산> < /dev/null`
- 프롬프트 요지: 16:9, 한 장면 · 한 장소의 인상. 오른쪽 아래 앞쪽에 청록 바람막이 · 올리브 바지 · 회청 모자를 쓴 여행자의 뒷모습(작게). 가운데에 단풍 · 자작 · 참나무 언덕, 왼쪽에 청록 바다와 흰 모래 해변, 먼 곳에 청회색 산줄기 층, 위에 흐린 가을 하늘. 두꺼운 유화 임파스토(팔레트 나이프 · 붓 결이 보이는 것), 참고 그림의 붓 크기와 빛 맞춤. 글자 · 로고 · 서명 · UI · 테두리 없음. 얼굴 없음(뒷모습만). 특정 화가 · 작품 · 게임 · 실제 건물 이름이나 모습은 넣지 않음.
- 참고 그림: 앱 화면 캡처 세 장(clean, HUD 없음), `shots/cover-m5/hwadam.png`, `shots/cover-m5/hyeopjae.png`, `shots/cover-m5/bukhansan.png` 를 1280 폭으로 줄인 사본. 붓 결 · 색 · 빛만 참고하고 장소의 모습은 베끼지 않았습니다.
